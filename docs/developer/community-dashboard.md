# Community Dashboard

A front end application that allows user to visualize answers to geospatial questions. 
![Citizen mapping tool](../_static/img/cv-portal-home.png)
![Citizen mapping tool](../_static/img/cv-dashboard.png)

## Tech Stack

- [NodeJS](https://nodejs.org/docs/latest/api/)
- [NuxtJS 3](https://nuxt.com/docs/getting-started/installation)
- [Pinia](https://pinia.vuejs.org/)
- [Vue](https://vuejs.org/)
- [LeafletJS](https://leafletjs.com/)

## Associated APIs

- [Civilian API](./apis.md)

## Running the App in Development

1. Install the dependencies.

```shell
cd cv-portal/
yarn install
```

2. Rund the App.

```shell
yarn run dev

# Press CTRL + C to stop the app
```
